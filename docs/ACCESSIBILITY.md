# Accessibility and keyboard use

Bloo works with touch, a hardware keyboard, a mouse, and a screen reader (TalkBack).

## Keyboard shortcuts

Press **F1** or **Ctrl + /** anywhere in the app to see this list. Shortcuts that act on a car need Ctrl, and the ones that
change something on the car need Shift as well, so a stray key never locks, unlocks or starts anything.

| Keys | Does |
| --- | --- |
| Ctrl + / or F1 | Show the shortcuts |
| Ctrl + K or Ctrl + F | Search settings |
| Ctrl + R or F5 | Refresh the car |
| Ctrl + PageDown or Ctrl + Tab | Next car |
| Ctrl + PageUp or Ctrl + Shift + Tab | Previous car |
| Ctrl + 1 to 9 | Go to that car |
| Ctrl + , | Open settings |
| Ctrl + L | Lock the car |
| Ctrl + Shift + U | Unlock the car |
| Ctrl + Shift + C | Start (smart climate) or stop the climate |
| Esc | Go back or close |

Tab and the arrow keys move between controls, and a ring shows which one has focus. Enter or Space presses a button or
picks a choice. A slider moves a step with the arrow keys (Home and End go to the ends; PageUp and PageDown move by a
tenth). Shortcuts do nothing while the app is locked, and none can reach a car from the sign-in or setup screens.

## Screen readers

- Each button is one item with its label and the Button role; switches say on or off; pickers say which choice is selected.
- A pebble says whether it is open or closed, and its action says "Expand" or "Collapse".
- The car's hero reads as one sentence: charge, range and state.
- Sliders can be adjusted with the screen reader's own increase and decrease gestures.
- Headings are marked, so a screen reader can jump between sections; messages are announced as they appear.

## Big screens

Tablets, folds and desktop windows show several cars side by side, and a car widens into two columns. The app handles
window resizes and a keyboard being attached without restarting.
